# C.M. Pulizie - Sito web con immagini reali

Questo ZIP contiene un sito web pronto da aprire o caricare su Codex.

## File principali

- `index.html` = pagina web.
- `style.css` = grafica.
- `script.js` = preventivo intelligente demo.
- `assets/` = immagini che hai inviato.
- `data/prodotto.json` = scheda del prodotto "Servizio Clienti".

## Come provarlo

1. Apri la cartella.
2. Fai doppio clic su `index.html`.
3. Vai alla sezione "Prenota".
4. Clicca su "Demo appartamento" o "Demo condominio".
5. Controlla il preventivo generato.
6. Spunta la revisione umana per copiare il messaggio.

## Importante

Il sito NON invia preventivi in automatico.
Il messaggio si può copiare solo dopo la spunta di revisione umana.
